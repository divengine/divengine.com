Database schemas

See your database the way it really is

Any analyzer (SchemaSpy works out of the box) sends Studio a snapshot of your schema. Explore thousands of tables on an interactive map, follow foreign keys column to column, and see exactly what changed between two snapshots.

  • Structure only, never row data
  • Immutable snapshots, pushed from CI after each migration
  • Visual diff: new tables in green, removed ones as red ghosts

Alongside your tools

Not another IDE, forge or tracker

Studio runs next to what your developers already use and connects to it, instead of replacing it.

What Studio is

  • Server software you install, on premises or in your cloud
  • The place for intent, models, decisions, process and verification
  • A reader of your Git repositories and database schemas
  • Free software you can extend like any Drupal site

What Studio is not

  • Not a SaaS: there is no account to rent, it's yours
  • Not a code editor nor a replacement for your Git host
  • Not your CI/CD or your infrastructure tooling
  • Not a black box: every rule and record is explicit
Self-hosted, open source

Your engineering knowledge, on your servers

Studio is a Drupal 11 distribution packaged as a recipe. Clone it, run composer install and one drush command, and you have the whole suite with roles, process definitions and sensible defaults.

  • GNU GPL v3: use it, study it, change it, share it
  • PHP 8.4 and PostgreSQL, the boring and reliable stack
  • Fine-grained roles, from testers to Studio Managers
Download & installRead the docs
git clone {{repo}}.git
cd studio && composer install
vendor/bin/drush site:install recipes/divengine_studio \
  --db-url=pgsql://studio:secret@localhost/studio \
  --account-name=admin
# That's it: log in and create your first Development.
