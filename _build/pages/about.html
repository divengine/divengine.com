Vision

Engineering discipline as infrastructure

Most of what a team knows about its software lives in people's heads, chat threads and slide decks. Divengine Studio exists to make that knowledge explicit, connected and checkable, with software doing the bookkeeping so that rigor stays light.

Explicit software engineering

Studio grew from the idea of explicit software engineering, the approach behind XSEM, the Explicit Software Engineering Method authored by rafageist: intent, models, decisions, work and validation should be explicit artifacts with traceable relationships, not implicit effort. Studio does not teach a methodology; it executes one. Today it ships with a full implementation of the Unified Process, tailorable through development cases.

It runs alongside the tools developers already love, IDEs, Git, CI pipelines and trackers, and connects to them instead of replacing them.

Roadmap

Built so far, and what comes next

  1. Engineering records & traceability Shipped

    Artifacts with types, lifecycles and revisions; typed trace links; record codes and [[CODE]] links.

  2. Modelers Shipped

    BPMN (bpmn-js) and UML (PlantUML in the browser), element links to records, diagrams embedded in text.

  3. Unified Process Shipped

    Developments, phases, iterations, milestones, activities, work products, development cases, readiness, change requests and baselines.

  4. Quality, work and knowledge Shipped

    Test management with evidence and QA issues, projects with Kanban boards, timesheets, knowledge base and discussions on every record.

  5. Code & databases Shipped

    Code Source indexed from Git, database schemas from any analyzer with explorer and evolution, MCP tools for AI agents.

  6. More notations Next

    Mermaid, DMN, ArchiMate, CMMN, IFML and Excalidraw, each with links from elements to records.

  7. Deeper analysis Next

    Database analysis runs with triage, schema dashboards, UML generated from schemas, richer reporting.

  8. Packaging & federation Later

    Easier installation (container images), and independent Studio instances collaborating through open APIs, with no central service.
